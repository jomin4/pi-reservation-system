# ADR-0003 — 키오스크 채널을 철회한다

| | |
|---|---|
| 상태 | 채택 · **소급 작성** |
| 날짜 | 2026-09-04 |
| 대체 | — |
| 관련 문서 | [overview.md](../overview.md) · [features.md](../features.md) · [search/korail-auth.md](../search/korail-auth.md) |

## 맥락

초기 기획은 **웹 · 모바일 · 키오스크 3채널**이었다. 코레일이 온라인과 현장 발권을 함께 운영하는 구조를 축소 재현하려던 것이고, 이게 프로젝트의 서사였다.

> **"인증 방식이 다른 채널을 하나의 Principal로 환원한다"**

진행하면서 두 가지가 막혔다.

| 막힌 것 | 내용 |
|---|---|
| **하드웨어** | Raspberry Pi 5 · 터치 디스플레이 · ESC/POS 프린터 확보 |
| **오프라인 결제** | 현장 카드 단말 계약이 개인에게 현실적으로 불가능 |

와이어프레임 `K-04`에서 이미 신호가 있었다 — **1024×600 화면에 좌석맵이 17px 초과**했고, 터치 최소 44px를 지키려면 하드웨어를 바꿔야 했다.

## 검토한 대안

| 대안 | 장점 | 단점 | 판정 |
|---|---|---|---|
| 유지 · 하드웨어 확보 | 서사 유지 | **비용 · 결제 계약 불가** | ❌ |
| 시뮬레이터로 대체 | 화면은 보여줄 수 있다 | **실물 없는 채널** — 정직하지 않다 | ❌ |
| **완전 철회** | 남는 것에 집중 | 서사를 다시 짜야 함 | ✅ **채택** |

## 결정

> **키오스크와 그에 딸린 모든 것을 철회하고, 서사를 다채널에서 좌석 동시성으로 재정의한다.**

함께 사라진 것:

| 항목 | |
|---|---|
| 임베디드 트랙 | C · libcurl · SQLite3 · ESC/POS · CMake |
| **비회원 예매 · 비로그인 조회** | 조회 PIN 5자리 포함 |
| **mTLS 디바이스 인증** | `DEVICE` · `GUEST` 역할 |
| QR 위임 결제 | 키오스크 전용이었음 |
| 티켓 출력 | |

**철회 ID는 재사용하지 않는다** — `F-11 · F-13 · F-23 · F-27~F-30 · F-32~F-35`.

## 결과

| 얻은 것 | 잃은 것 |
|---|---|
| **인증 경로가 JWT 하나** | 다채널 서사 |
| 서사가 **"정확히 하나만 성공시킨다"**로 선명해짐 | 코레일과 갈리는 지점(비회원 예매) |
| 구매 목록에서 4개 품목 삭제 | 조사 문서 §5~§7 재작성 |

**ADR-0001의 배당금이 여기서 나왔다.**

> **`:adapter-kiosk` 제거는 `:bootstrap`의 의존 한 줄 삭제로 끝났다.** 코어와 다른 어댑터는 한 글자도 안 바뀌었다 — 경계가 제대로 그어졌다는 증거다.

## 되돌린다면

| 항목 | 비용 |
|---|---|
| 어댑터 추가 | **싸다** — 헥사고날이라 코어를 안 건드린다 |
| 인증 경로 분기 | 중간 — `DEVICE` 역할과 mTLS를 되살려야 |
| **하드웨어 · 결제 계약** | ⚠️ **여전히 막혀 있다** |
| **비싼 이유** | 기술이 아니라 **현실 제약**이라 코드로 풀리지 않는다 |
