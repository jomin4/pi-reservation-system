# ADR-0006 — 백업을 Cloudflare R2 오프사이트 한 벌로 한다

| | |
|---|---|
| 상태 | 채택 |
| 날짜 | 2026-09-10 |
| 대체 | 초기안 — 외장 USB RAID 백업 (ADR 없음) |
| 관련 문서 | [tech.md](../tech.md) · [data.md §7.8](../data.md) · [system-architecture](../diagrams/system-architecture.html) |

## 맥락

초기안은 **외장 USB RAID**였다. ADR-0005로 호스트가 개인 PC로 바뀌면서 백업 전략을 다시 봤고, **3-2-1 규칙을 못 지키고 있다**는 게 드러났다.

| 규칙 | 초기안 |
|---|---|
| 3벌 | SSD + USB = **2벌** |
| 2매체 | ✅ |
| **1 오프사이트** | ❌ **0** |

> **집에 불나면 원본과 백업이 같이 사라진다.** USB RAID는 *디스크 고장*은 막지만 *장소 사고*는 못 막는다.

## 검토한 대안

| 대안 | 오프사이트 | 메모리 | 이그레스 | 판정 |
|---|---|---|---|---|
| USB RAID 유지 | ❌ | 0 | — | ❌ |
| **MinIO 자체 호스팅** | ❌ **같은 SSD** | **+0.5 GB 상주** | — | ❌ |
| AWS S3 | ✅ | 0 | **유료** | ❌ |
| **Cloudflare R2** | ✅ | 0 | **무료** | ✅ **채택** |

**MinIO를 거른 이유가 이 결정에서 가장 중요하다.**

> **백업의 정의는 "원본과 운명을 공유하지 않는 사본"이다.** MinIO를 같은 PC에 띄우면 **디렉터리를 하나 더 만든 것**에 불과하고, 8GB 예산에서 0.5GB를 내주기까지 한다. MinIO는 **별도 머신이 있을 때의 선택지**다.

**R2를 고른 결정적 이유는 이그레스 무료다.** 복구를 자주 연습해야 백업이 백업인데, **다운로드가 유료면 리허설을 아끼게 된다.** 그리고 `외부 = Cloudflare 통일`이 이미 확정돼 있어 외부 의존 주체가 안 늘어난다.

## 결정

> **R2 한 벌만 둔다. USB RAID는 철회한다.** 전송 전에 `age`로 암호화한다.

```
pg_dump -Fc | age -r <공개키> | rclone rcat r2:pi-backup/db/$(date +%F).age
```

| 항목 | 값 |
|---|---|
| 대상 | **PostgreSQL 하나** |
| 주기 | 일 1회 |
| 크기 | `pg_dump -Fc` **~20 MB** · 30일 보관 시 ~600 MB (무료 티어 10 GB) |
| 암호화 | **`age` 공개키** — 복호화 키를 호스트에 두지 않는다 |
| 경로 | **tinyproxy 화이트리스트** 경유 |

### Redis를 백업하지 않는다

| 워크로드 | 잃으면 | 백업 가치 |
|---|---|---|
| 좌석맵 캐시 | PG에서 재생성 | 0 |
| Stream | 재개 창일 뿐 | 0 |
| Refresh 토큰 | **전원 재로그인** | 낮음 |
| 시도 제한 | TTL 5분 | 0 |

> **AOF는 재시작 생존용이지 재해 복구용이 아니다.** 토큰을 복원해봐야 그 사이 사용자는 이미 다시 로그인했다.

### 암호화가 선택이 아닌 이유

`member` 테이블에 **이메일 · 전화번호 · 비밀번호 해시**가 있다. **폐쇄망을 설계 주제로 내건 프로젝트가 백업은 평문으로 외부에 올리면** 그 서사가 통째로 무너진다.

## 결과

| 얻은 것 | 잃은 것 |
|---|---|
| **3-2-1의 오프사이트 확보** | 로컬 사본 — 복구가 네트워크를 탄다 |
| 복구 리허설이 무료 | **외부 출구 +1** (화이트리스트 2곳) |
| 물리 매체 관리 불필요 | 키 관리 책임 (`age` 개인키) |

**복구 검증은 새로 만들지 않는다.**

> **`data.md` §7.8의 시드 검증 쿼리가 그대로 복구 검증 쿼리가 된다.** "`trip_seat` 480,000행 · 열차번호 홀짝이 방향과 일치"를 복구본에 돌리면 된다. **월 1회 리허설.**
