# 2026-09-10 — 워크플로가 큐잉은 되는데 job 이 하나도 시작되지 않고 커밋마다 빨간 X 가 뜬다

| | |
|---|---|
| 상태 | 해결 (2026-09-11) |
| 트랙 | tooling |
| 관련 | `docs/deploy.md` §1 · `docs/workflow.md` §8 |

## 증상

push 마다 CI 가 실패로 표시된다. 워크플로는 정상 등록되고 큐에 들어가는데, **job 이 시작되는 순간 거부**된다. 로그에 이 한 줄만 남는다.

```
The job was not started because your account is locked due to a billing issue.
```

`forbidden.yml` · `docs-ci.yml` 등 **모든 워크플로가 같은 증상**이었다. 특정 YAML 의 문제라면 그 파일만 실패해야 한다.

## 환경

| 항목 | 값 |
|---|---|
| 저장소 | public — Actions 분은 **무료** |
| 재현 | 항상. 2026-09-10 ~ 09-11 |

## 원인

**GitHub 계정의 결제 잠금.** public 저장소라 Actions 분이 무료인 건 맞지만, **계정이 잠기면 무료분도 나가지 않는다.** 워크플로 파일 · 러너 · 권한과 무관하다 — 계정 상태가 job 시작을 막는다.

## 해결

GitHub **Settings → Billing and licensing** 에서 결제수단·미납을 확인하고 풀었다. 풀리자 **다음 push 부터 아무 변경 없이 그대로 돌았다.** 워크플로 파일은 한 줄도 안 고쳤다.

## 막다른 길

| 시도 | 결과 |
|---|---|
| YAML 문법 의심 — `action-validator` 로 전부 검사 | **전부 통과.** 파일 문제가 아니었다 |
| 트랙 판별(`_changes.yml`) · 페이로드 로컬 재현 | 정상. **로컬에서 되는데 GitHub 에서만 안 되면 파일 밖을 의심해야 했다** |
| 브랜치 보호로 필수 체크 걸기 | ⚠️ **하면 안 된다.** 필수 체크가 영영 실패해 **모든 PR 이 막힌다.** 잠금이 풀릴 때까지 끄고 있었다 |

> **에러 메시지가 원인을 정확히 가리키고 있었다** (`billing issue`). 그런데도 코드 쪽을 먼저 뒤진 건, "public 저장소는 무료" 라는 전제가 "그러니 결제 문제일 리 없다" 로 이어졌기 때문이다. **무료분도 계정이 잠기면 안 나간다.**
